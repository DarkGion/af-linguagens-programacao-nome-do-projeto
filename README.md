## Funcionalidades
- Menu responsivo utilizando Navbar do Bootstrap
- Carrossel de imagens dinâmico
- Galeria de imagens organizada com Bootstrap Grid
- Formulário de contato validado
- Mapa interativo incorporado (Google Maps)
- Animações CSS (Fade In, Escala de Imagens e Hover em Cards)
- Interação com JavaScript: Botão "Voltar ao Topo"
- Interação com JavaScript: Validação de Campos do Formulário
- Interação com JavaScript: Alternância de Tema Claro/Escuro
- Organização baseada em Flexbox para alinhamento e estrutura responsiva
